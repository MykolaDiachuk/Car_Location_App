3c. Карта парковки

Малюйте полігони на BEV. Клік — нова вершина, подвійний клік або Enter — замикає полігон.

Режим
В режимі редагування: drag — переміщення вершини,
Shift+click на ребрі — вставити вершину,
Delete — видалити вершину/полігон.

    4. Експорт

    Перевірте статус кожного артефакту та завантажте ZIP.

    Як вставити в основний проєкт
    1. Розпакуйте parking_config.zip у корінь репозиторію основного проєкту.
    2. Файли assets/parking_mask.png, assets/orientation_zones.png, assets/parking_map.svg замінять (або створять) існуючі в assets/.
    3. Перейменуйте .env.example на .env якщо ще не зробили і підмерджте змінні з нашого .env.
    4. Для того щоб бекенд читав SRC_POINTS з .env, потрібен невеликий патч до config.py: 
      import json
src_json = os.getenv("SRC_POINTS")
SRC_POINTS_DEFAULT = [[-303,-163],[2070,339],[3165,1062],[831,1250]]
SRC_POINTS = np.array(
    json.loads(src_json) if src_json else SRC_POINTS_DEFAULT,
    dtype=np.float32,
)
BEV_WIDTH = int(os.getenv("BEV_WIDTH", "1200"))
BEV_HEIGHT = int(os.getenv("BEV_HEIGHT", "800"))
    5. Запустіть python monitor.py або підніміть API сервер — нові налаштування підтягнуться з .env.
