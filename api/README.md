# Parking Monitor API — Specification

FastAPI server that exposes real-time parking lot occupancy over HTTP.

## Running

```bash
uvicorn api.server:app --host 0.0.0.0 --port 8000
```

Interactive docs auto-generated by FastAPI: `http://localhost:8000/docs`

## Environment variables

| Variable | Default | Description |
|---|---|---|
| `CAMERA_URL` | from `config.py` | RTSP stream URL |
| `MOCK_MODE` | `false` | `true` skips camera/YOLO, uses synthetic data |
| `CORS_ORIGINS` | `*` | Comma-separated allowed origins, or `*` |
| `ANALYSIS_INTERVAL` | `1.0` | Seconds between pipeline runs while active |
| `IDLE_TIMEOUT` | `30.0` | Seconds of no client polls before pipeline pauses |
| `STALE_THRESHOLD` | `10.0` | Seconds after which a snapshot is marked `stale=true` |
| `DB_PATH` | `/data/parking_history.db` | SQLite history database file path |
| `RECORD_INTERVAL` | `120.0` | Minimum seconds between successive DB writes |
| `RETENTION_DAYS` | `90` | Snapshots older than this are deleted at startup |

## Endpoints

### `GET /api/v1/history`

Returns historical occupancy data for chart rendering. Does **not** mark client activity — the pipeline will not wake up from idle just because history is fetched.

**Query parameters** — provide either `period` **or** `from`/`to`:

| Param | Type | Example | Description |
|---|---|---|---|
| `period` | string | `1h`, `24h`, `7d`, `30d` | Lookback window from now |
| `from` | ISO 8601 | `2025-01-01T00:00:00Z` | Start of custom range |
| `to` | ISO 8601 | `2025-01-02T00:00:00Z` | End of range (defaults to now) |

Default when no params: last 24 hours. Maximum range: 90 days.

Aggregation is applied automatically to keep ~120–360 points per response:

| Time span | Bucket size | Notes |
|---|---|---|
| ≤ 1 h | raw (no averaging) | Every recorded snapshot |
| ≤ 6 h | 60 s | 1-minute averages |
| ≤ 24 h | 300 s | 5-minute averages |
| ≤ 7 d | 1 800 s | 30-minute averages |
| > 7 d | 7 200 s | 2-hour averages |

**Response `200 OK`:**

```json
{
  "period_from": "2025-01-01T00:00:00Z",
  "period_to":   "2025-01-08T00:00:00Z",
  "bucket_seconds": 1800,
  "point_count": 229,
  "points": [
    {
      "timestamp": "2025-01-01T00:00:00Z",
      "total_spots": 15,
      "occupied": 4,
      "free": 11,
      "occupancy_percent": 26.7
    }
  ]
}
```

`bucket_seconds: 0` — raw data, no aggregation applied.

**Error responses:**

| Status | When |
|---|---|
| `400` | Invalid `period` format, `from >= to`, range > 90 days, or both `period` and `from` provided |

### `GET /api/v1/state`

Returns the latest parking snapshot. **Also marks the client as active** — polling this endpoint keeps the pipeline running. If no one polls for `IDLE_TIMEOUT` seconds, the camera is released and the pipeline pauses.

**Response `200 OK`:**

```json
{
  "timestamp": "2026-05-03T12:00:00.000Z",
  "age_seconds": 0.84,
  "stale": false,
  "pipeline_status": "running",
  "bev_width": 1200,
  "bev_height": 800,
  "total_spots": 7,
  "occupied": 3,
  "free": 4,
  "occupancy_percent": 42.9,
  "spots": [
    {
      "id": 0,
      "status": "free",
      "orientation": "parallel",
      "center_bev": { "x": 0.15, "y": 0.65 },
      "bbox_bev": { "x1": 525, "y1": 480, "x2": 675, "y2": 560 },
      "confidence": 0.91
    }
  ]
}
```

**Response `503 Service Unavailable`** — pipeline is starting and has no snapshot yet. Retry after 1–2 seconds.

```json
{ "detail": "Pipeline starting — no snapshot yet. Retry shortly." }
```

### `GET /api/v1/health`

Operational health check. Does **not** mark client activity — safe to poll from uptime monitors without keeping the pipeline awake.

**Response `200 OK`:**

```json
{
  "status": "ok",
  "uptime_seconds": 142.5,
  "pipeline": {
    "status": "running",
    "frames_processed": 138,
    "errors": 0,
    "last_error": null
  },
  "camera": {
    "connected": true,
    "last_frame_at": "2026-05-03T12:00:00.000Z"
  },
  "bev_width": 1200,
  "bev_height": 800
}
```

## Data types

### `HistoryPoint`

Single data point returned in `/api/v1/history`.

| Field | Type | Notes |
|---|---|---|
| `timestamp` | ISO 8601 datetime (UTC) | Bucket start time when aggregated, exact time when raw |
| `total_spots` | `int` | Total parking spots detected |
| `occupied` | `int` | Occupied spots (averaged and rounded when aggregated) |
| `free` | `int` | Free spots (averaged and rounded when aggregated) |
| `occupancy_percent` | `float [0–100]` | `occupied / total_spots * 100`, rounded to 1 decimal |

### `HistoryResponse`

| Field | Type | Notes |
|---|---|---|
| `period_from` | ISO 8601 datetime | Start of the queried range |
| `period_to` | ISO 8601 datetime | End of the queried range |
| `bucket_seconds` | `int` | Aggregation window in seconds; `0` = raw |
| `point_count` | `int` | Number of points in `points` array |
| `points` | `HistoryPoint[]` | Ordered chronologically |

---

### `PipelineStatus`

| Value | Meaning |
|---|---|
| `"starting"` | Worker thread is initializing or reconnecting to camera |
| `"running"` | Actively processing frames |
| `"idle"` | No recent client polls — camera released, pipeline paused |
| `"error"` | Camera unreachable or processing failure; auto-retrying |

### `SpotStatus`

`"free"` | `"occupied"`

### `SpotOrientation`

`"parallel"` | `"perpendicular"`

### `ParkingSpot`

| Field | Type | Notes |
|---|---|---|
| `id` | `int` | Unique within one response. **Not stable** across frames — do not persist. |
| `status` | `SpotStatus` | |
| `orientation` | `SpotOrientation` | Painted in `orientation_zones.png` |
| `center_bev` | `NormalizedPoint` | `x`, `y` in range `[0.0, 1.0]` relative to BEV canvas |
| `bbox_bev` | `BBox` | `x1 y1 x2 y2` in BEV pixels |
| `confidence` | `float [0–1]` | YOLO detection confidence |

### `NormalizedPoint`

Coordinates normalized to `[0.0, 1.0]` relative to `bev_width` / `bev_height`.  
To convert to pixels on a canvas of size `W × H`:

```
pixel_x = center_bev.x * W
pixel_y = center_bev.y * H
```

### `BBox`

Axis-aligned bounding box in **BEV pixel coordinates** (not normalized).  
Origin is top-left. Scale to your canvas using `bev_width` / `bev_height`.

## Activity-driven pipeline

The pipeline only runs while clients are actively polling `/api/v1/state`.

```
Client polls /api/v1/state
  → _mark_activity() resets idle timer
  → pipeline wakes up if it was idle
  → camera connects, frames processed
  → 30 s with no polls → camera released, pipeline sleeps
```

On the first poll after an idle period, the response returns the **last cached snapshot** immediately (potentially stale). Fresh data arrives on the next poll ~1 second later.

## CORS

By default all origins are allowed (`*`). To restrict:

```bash
CORS_ORIGINS="https://your-frontend.com,https://staging.your-frontend.com"
```

Only `GET` methods are exposed.
