# Parking Monitor API — Specification

FastAPI server that exposes real-time parking lot occupancy over HTTP.

> **Configuration reference:** all environment variables are documented in
> [`docs/configuration.md`](../docs/configuration.md). This page covers
> only the HTTP contract: endpoints, query parameters, response shapes.

## Running

```bash
uvicorn api.server:app --host 0.0.0.0 --port 8000
```

Interactive auto-generated docs: <http://localhost:8000/docs>.

---

## Endpoints

| Method | Path | Marks activity? | Description |
|---|---|---|---|
| `GET` | `/api/v1/state` | ✅ yes | Latest parking snapshot. Polling this keeps the pipeline running. |
| `GET` | `/api/v1/history` | ❌ no | Historical occupancy for chart rendering. |
| `GET` | `/api/v1/health` | ❌ no | Operational health check. Safe for monitoring dashboards. |
| `GET` | `/api/v1/system` | ❌ no | Host CPU / RAM / disk / network metrics. |
| `GET` | `/` | ❌ no | API index — discoverable links to all endpoints. |
| `GET` | `/docs` | — | Swagger UI (generated by FastAPI). |
| `GET` | `/web/` | — | Bundled browser dashboard. |
| `GET` | `/assets/` | — | Static parking-mask / BEV images. |

"Marks activity" means polling that endpoint resets the idle timer that
keeps the pipeline running. See
[`docs/architecture.md#activity-driven-pipeline`](../docs/architecture.md#activity-driven-pipeline).

### `GET /api/v1/state`

Returns the latest parking snapshot. **Polling this keeps the pipeline
alive** — after `IDLE_TIMEOUT` seconds (default 30) without a poll, the
camera is released.

**Response `200 OK`:**

```json
{
  "timestamp": "2026-05-15T12:00:00.000Z",
  "age_seconds": 0.84,
  "stale": false,
  "pipeline_status": "running",
  "bev_width": 1200,
  "bev_height": 800,
  "total_spots": 7,
  "occupied": 3,
  "free": 4,
  "occupancy_percent": 42.9,
  "spots": [
    {
      "id": 0,
      "status": "free",
      "orientation": "parallel",
      "center_bev": { "x": 0.15, "y": 0.65 },
      "bbox_bev": { "x1": 525, "y1": 480, "x2": 675, "y2": 560 },
      "confidence": 0.91
    }
  ]
}
```

`stale: true` when snapshot age exceeds `STALE_THRESHOLD` (default 10 s).

**Response `503 Service Unavailable`** — pipeline is starting and has no
snapshot yet. Retry after 1–2 seconds.

```json
{ "detail": "Pipeline starting — no snapshot yet. Retry shortly." }
```

### `GET /api/v1/history`

Returns historical occupancy data for chart rendering.

**Query parameters** — provide either `period` **or** `from`/`to`:

| Param | Type | Example | Description |
|---|---|---|---|
| `period` | string | `1h`, `24h`, `7d`, `30d` | Lookback window from now |
| `from` | ISO 8601 | `2026-01-01T00:00:00Z` | Start of custom range |
| `to` | ISO 8601 | `2026-01-02T00:00:00Z` | End of range (defaults to now) |

Default when no params: last 24 hours. Maximum range: 90 days.

**Auto-aggregation** keeps the response at ~120–360 points:

| Time span | Bucket size |
|---|---|
| ≤ 1 h | raw (no averaging) |
| ≤ 6 h | 60 s (1-minute averages) |
| ≤ 24 h | 300 s (5-minute averages) |
| ≤ 7 d | 1 800 s (30-minute averages) |
| > 7 d | 7 200 s (2-hour averages) |

**Response `200 OK`:**

```json
{
  "period_from": "2026-01-01T00:00:00Z",
  "period_to":   "2026-01-08T00:00:00Z",
  "bucket_seconds": 1800,
  "point_count": 229,
  "points": [
    {
      "timestamp": "2026-01-01T00:00:00Z",
      "total_spots": 15,
      "occupied": 4,
      "free": 11,
      "occupancy_percent": 26.7
    }
  ]
}
```

`bucket_seconds: 0` means raw data, no aggregation applied.

**Error responses:**

| Status | When |
|---|---|
| `400` | Invalid `period` format, `from >= to`, range > 90 days, or both `period` and `from` provided |

### `GET /api/v1/health`

Operational health check. Does NOT mark client activity — safe to poll
from external uptime monitors.

**Response `200 OK`:**

```json
{
  "status": "ok",
  "uptime_seconds": 142.5,
  "pipeline": {
    "status": "running",
    "frames_processed": 138,
    "errors": 0,
    "last_error": null
  },
  "camera": {
    "connected": true,
    "last_frame_at": "2026-05-15T12:00:00.000Z"
  },
  "bev_width": 1200,
  "bev_height": 800
}
```

`status`: `"ok"` | `"degraded"` | `"error"` | `"starting"`.

---

### `GET /api/v1/system`

Host resource metrics. Returns the latest sample plus a rolling history
buffer (used by the dashboard's system panel).

```json
{
  "server": { "hostname": "...", "platform": "...", "python": "3.11.x" },
  "current": { "cpu_percent": 18.4, "ram_percent": 42.1, "disk_percent": 31.0, "...": "..." },
  "history": [ { "timestamp": "...", "cpu_percent": 18.4, "...": "..." } ]
}
```

---

### `GET /`

API discovery — points clients at the docs and main endpoints.

```json
{
  "name": "Parking Monitor API",
  "version": "1.0.0",
  "endpoints": {
    "state":   "/api/v1/state",
    "health":  "/api/v1/health",
    "history": "/api/v1/history",
    "system":  "/api/v1/system",
    "docs":    "/docs",
    "ui":      "/web/"
  }
}
```

## Data types

### `HistoryPoint`

Single data point returned in `/api/v1/history`.

| Field | Type | Notes |
|---|---|---|
| `timestamp` | ISO 8601 datetime (UTC) | Bucket start time when aggregated; exact time when raw |
| `total_spots` | `int` | Total parking spots detected |
| `occupied` | `int` | Occupied spots (averaged and rounded when aggregated) |
| `free` | `int` | Free spots (averaged and rounded when aggregated) |
| `occupancy_percent` | `float [0–100]` | `occupied / total_spots * 100`, rounded to 1 decimal |

### `HistoryResponse`

| Field | Type | Notes |
|---|---|---|
| `period_from` | ISO 8601 datetime | Start of the queried range |
| `period_to` | ISO 8601 datetime | End of the queried range |
| `bucket_seconds` | `int` | Aggregation window in seconds; `0` = raw |
| `point_count` | `int` | Number of points in `points` array |
| `points` | `HistoryPoint[]` | Ordered chronologically |

### `PipelineStatus`

| Value | Meaning |
|---|---|
| `"starting"` | Worker is initialising or reconnecting to the camera |
| `"running"` | Actively processing frames |
| `"idle"` | No recent client polls — camera released, pipeline paused |
| `"error"` | Camera unreachable or processing failure; auto-retrying |

### `SpotStatus`

`"free"` | `"occupied"`

### `SpotOrientation`

`"parallel"` | `"perpendicular"`

### `ParkingSpot`

| Field | Type | Notes |
|---|---|---|
| `id` | `int` | Unique within one response. **Not stable** across frames — do not persist. |
| `status` | `SpotStatus` | |
| `orientation` | `SpotOrientation` | Painted in `orientation_zones.png` |
| `center_bev` | `NormalizedPoint` | `x`, `y` in range `[0.0, 1.0]` relative to BEV canvas |
| `bbox_bev` | `BBox` | `x1 y1 x2 y2` in BEV pixels |
| `confidence` | `float [0–1]` | YOLO detection confidence |

### `NormalizedPoint`

Coordinates normalized to `[0.0, 1.0]` relative to `bev_width` /
`bev_height`. To convert to pixels on a canvas of size `W × H`:

```
pixel_x = center_bev.x * W
pixel_y = center_bev.y * H
```

### `BBox`

Axis-aligned bounding box in **BEV pixel coordinates** (not normalized).
Origin is top-left. Scale to your canvas using `bev_width` / `bev_height`.

## CORS

By default all origins are allowed (`*`). To restrict, set in `.env`:

```bash
CORS_ORIGINS="https://your-frontend.com,https://staging.your-frontend.com"
```

Only `GET` methods are exposed.
